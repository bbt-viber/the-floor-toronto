COLOURS TRIVIA — 40 images (15 Easy / 15 Medium / 10 Hard)
All images 1200x1000 PNG. Filename = the answer.

Each card is just one solid block of colour, edge to edge — no text,
no border, nothing else. Players name the colour.

Every shade is the standard reference definition of that colour name:
the web (CSS/X11) colour standard where one exists, and Wikipedia's
reference value for the rest. The hex codes are listed below so any
card can be checked. Screens vary a little, but these are the
canonical values.

NOTES / JUDGMENT CALLS
- Fuchsia is not in the set: on a screen it is literally the same
  colour as magenta (#FF00FF), so the two could never be told apart.
  Same story for aqua and cyan (#00FFFF) — only cyan is in.
- Gold is the flat standard gold. A screen can't do metallic shimmer,
  so it reads as a rich yellow-gold.
- Khaki uses #C3B091, the trousers colour. (The web standard's
  "khaki" is a pale yellow that nobody means by the word.)
- Aubergine uses Wikipedia's eggplant value (#614051), a deep purple
  that still reads as purple — some references use a near-black
  #3D0734, which would be unguessable on most screens.
- Closest pairs, for the host: Salmon vs Coral (salmon is pinker and
  lighter, coral more orange); Maroon vs Burgundy (burgundy has a
  wine/purple lean); Lavender vs Periwinkle vs Mauve (lavender is the
  palest, periwinkle leans blue, mauve leans pink).
