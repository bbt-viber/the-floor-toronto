NBA + WNBA team logos - text-free trivia set
==============================================
40 images in this single folder, each 1200x1000 on a white background,
named by team. Every image shows the team's FULL logo. Where the logo
contains the team's name or city in text, each team's nickname has been removed with an AI fill;
the city name is kept, and the artwork is left intact.
